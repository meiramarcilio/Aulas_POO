# Comandos básicos para Aula de POO com C# no Visual Code

### Criar novo projeto

dotnet new console -n "NomePasta"

### Compilar o projeto

dotnet build

### Rodar o app

dotnet run

### Criar projeto Windows Form no VS Code

dotnet new winforms -n "AulaWindowsForm1"

#### Instalar Extensão:

WinForms Designer for VS Code

A extensão WinForms Designer 2.2.0 requer o .NET 10 Desktop Runtime no Windows. Após
instalá-lo, reinicie o VS Code para que a extensão consiga iniciar o designer.
